# 🍎 水果成本记账 App (FruitPriceTracker)

这是一个专为水果店/水果批发采购打造的**独立手机记账与价格对比 App**。支持记录每天的水果进货成本价、自定义水果种类与计价单位、自动与昨日价格对比涨跌、查看历史价格折线图、导出 Excel 报表以及联网云端同步。

---

## ✨ 已实现核心功能

1. **每日成本记账与昨日对比（核心）**
   - 自动计算并展示当日成本与昨日（或上次记录）的**涨跌金额**与**涨跌百分比**（如 `↑ +0.30 (+6.7%)` 红字提示成本上涨，`↓ -0.30 (-8.6%)` 绿字提示成本下降，`持平 0.00`）。
   - 支持 **⚡ 一键沿用昨日价格**：未变动的水果无需重复手输，1 秒填入昨日价格，只需修改今日有波动的品种。
   - 支持 **`-0.5` / `+0.5` 快捷微调按钮**与进货备注（如“一级果80#”、“产地雨天微涨”）。
2. **按日期补录与往期价格查询**
   - 顶部配备日期切换器（`前一天` / `日期日历选择` / `后一天` / `回到今天`），可随时查看往期某天的价格表或补录漏记的日期，补录时也会自动与该日期的前一天做对比。
3. **自定义水果种类与多计价单位**
   - 可自由添加、编辑、排序、删除水果品种（支持自定义图标、名称、分类）。
   - 支持随时切换计价单位：**`元/斤`、`元/公斤`、`元/箱`、`元/件`、`元/筐`、`元/盒`、`元/个`**。
4. **历史价格趋势折线图与涨跌排行**
   - 内置高清 SVG 价格走势折线图，支持切换 **近7天 / 近14天 / 近30天 / 全部**，自动统计最高价、最低价、平均成本价。
   - 提供当日全品种涨跌幅度排行榜与单品历史明细表。
5. **数据导入/导出备份 & 联网云端同步**
   - **导出 Excel (CSV)**：内置 UTF-8 BOM 编码，导出的 `.csv` 文件直接用手机 WPS 或电脑 Excel 打开不乱码。
   - **JSON 完整备份与恢复**：支持一键导出 `.json` 备份文件及导入恢复，换手机不丢数据。
   - **联网云端同步**：实时监测手机联网状态，支持配置云端 API 地址（如 JSONBin / 自建接口）实现一键上传与拉取同步。

## 🚀 如何立即打开体验？

1. **方式 A（最快，无需安装任何环境）**：
   - 直接双击项目文件夹中的 **[启动预览.bat](./启动预览.bat)**，或直接用浏览器打开 **[www/index.html](./www/index.html)** 即可立即体验完整功能！
2. **方式 B（打包成独立手机安装包 `.apk` 下载安装）**：
   - **云端免安装环境自动打包（推荐）**：
     1. 将本文件夹上传到您的 GitHub 仓库（项目已内置 [`.github/workflows/build-apk.yml`](./.github/workflows/build-apk.yml) 自动构建配置）。
     2. 打开 GitHub 仓库的 **Actions** 页面，运行 `自动构建安卓安装包 (Build Android APK)`。
     3. 等待约 2 分钟构建完成后，直接下载生成的 `水果成本记账-Android安装包-APK` 发送到手机安装即可！
   - **本地电脑打包（需安装 Node.js 与 Android Studio）**：
     ```bash
     npm install
     npx cap add android
     npx cap sync android
     npx cap open android
     ```
     在打开的 Android Studio 中点击 `Build -> Build Bundle(s) / APK(s) -> Build APK(s)` 即可生成独立安装包。
